## 已实现的边界

- 使用官方固定网关 `https://open.weibo.com/cli/api`，Bearer 凭证只在请求头中，禁止重定向转发。
- 搜索入口：`search / statuses/limited`；外部账号动态：`statuses / user_timeline/other`，不是自己的运营接口 `/biz`。
- 调用前读取该命令的实时 metadata，兼容官方 `{command:{flags:[]}}` 包装。只有接口声明了 `page/count/isGetLongText` 才传递相应参数。
- 读取不到参数、授权过期、权限不足、限流或结果结构不符时，记录明确状态；不冒充“今天暂无消息”。
- 同一来源内给所有目标预留调用预算，防止列表末尾目标永远不被执行；跨查询去重不作为提前停止翻页的依据。
- 记录原帖 ID、账号、原文链接、原始时间、发现时间和转发属性。图片/视频字段提取为兼容实现，实际字段和展示效果仍需授权样本验证。
- 图片、长文、视频缺失不阻止其他消息发布。账号认证、转发或重复搜索命中不会自动提高可信度。
- 请求窗口或预算用尽标为覆盖受限，不宣称微博全量覆盖。

## 授权后的必做验收

1. 用一个搜索和一个外部账号样本检查 metadata、result、outcome 的真实结构，修正适配器；离线 fixture 不能代替这一步。
2. 核实目标账号 UID：拟覆盖片方、视频平台、主创、行业媒体；不能仅凭名称猜 UID。将核实后的 UID 写入账号配置，再启用。
3. 根据真实 API 支持的时间、排序、分页参数选择最新消息策略。目前未验证搜索结果默认排序，不能承诺当前两个种子查询就足以覆盖当天资讯。
   种子查询的地区尚未分类，暂归“行业观察”，不会因原帖是中文就自动归为“中国内地”；正式覆盖时应按作品或事件核实地区。
4. 加入定档、开机、杀青、预告、海报、发行、电影节等查询，并在预算内验证遗漏率与噪声。检索无结果不是全网无新闻。
5. 检查图片、视频回链和原帖时间；转发只代表该账号转发时间，不冒称原消息首次发布。
6. 明确 token 到期与续期方案。**当前适配器只支持 access token，没有实现 refresh token 的安全轮换持久化。** 不能承诺配置一次就永久自动运行。官方 SDK 的环境变量 refresh 方案也不会自动保存轮换后的凭证，因此不能简单增加一个 Secret 就宣称解决。
7. 完成真实样本、持续运行和预算验收后，再同步并部署到原项目。当前本地有此前未发布修改，且分支与远端存在差异，不能直接用本地旧版本覆盖线上。
